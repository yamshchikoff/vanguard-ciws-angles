ВЫВОД
-----
Отрицательный угол вертикальной наводки Vanguard CIWS ≈ 0°: ствол не опускается
ниже горизонта. Надёжные (класс A, два согласных семейства линий) покадровые
линейные замеры: −5.7°…+1.9° (вниз +), среднее −0.8°; максимальный «вниз» +1.9°±1.5°.
За ~6 минут работы за турелью (4 видео) наведение ни разу достоверно не ушло
ниже горизонта. Машинно-читаемые данные: out/*.csv, графики: out/*.png.

КАК ВОСПРОИЗВЕСТИ
-----------------
ffmpeg (static):        см. scripts/ffmpeg (исключён из репо; apt install ffmpeg)
yt-dlp:                 см. scripts/yt-dlp (исключён; pip install yt-dlp)
Кадры 1 к/с из видео:   ffmpeg -i video.mp4 -vf "fps=1,scale=960:540" frames/ljs1f/%04d.jpg
Кадры 4 к/с участка:    ffmpeg -ss 219 -t 313 -i video.mp4 -vf "fps=4,scale=960:540" frames/ljs4f/%05d.jpg
Покадровый замер:       python3 scripts/pitch_perframe2.py "frames/ljs4f/*.jpg" 2 2.0 out/pitch_perframe_2fps.csv
График эволюции:        python3 scripts/pitch_evo_lines.py out/pitch_perframe_2fps.csv out/pitch_evolution_lines.png
Интегральный график:    python3 scripts/pitch_series.py && python3 scripts/pitch_plot2.py
VP-тест одного кадра:   python3 scripts/vpsoft.py (функция vps_soft) / scripts/scan2.py

МЕТОД (кратко)
--------------
POV оператора жёстко привязан к стволам: прицел строго в центре, точка схода стволов = центр.
Для камеры без крена любое мировое горизонтальное семейство линий даёт точку схода на строке
горизонта. Класс A: два разных семейства согласны по строке горизонта → наклон = atan((cy−y_h)/f),
f≈720px при 960x540 (дефолтный FOV 90° × зум прицела 1.5x; при другом FOV шкала ×720/f).
Класс B (одно семейство) — предварительный, шум. Интегральная версия (фазовая корреляция)
даёт непрерывность, но дрейфует на разрывах; покадровая — абсолютная, без дрейфа.
