# WARDOGS Vanguard CIWS — угол вертикальной наводки (отрицательный)

Фотограмметрический замер угла склонения турели **Vanguard CIWS** из игры WARDOGS
(Steam app 1867240, BULKHEAD/Team17) по видеозаписям работы за турелью.

**Вывод: отрицательный угол вертикальной наводки ≈ 0° — ствол не опускается ниже
горизонта.** Надёжные (класс A) покадровые замеры наклона лежат в диапазоне
**−5.7° … +1.9°** (вниз положительный), среднее −0.8°; максимум «вниз» = **+1.9° ± 1.5°**
(и по кадру это визуально уровень). В официальных источниках и базах данных значение
не публикуется — цифры получены измерительно.

## Метод (кратко)

POV оператора жёстко привязан к стволам: прицел строго в центре кадра, точка схода стволов = центр.
Для камеры без крена любое мировое горизонтальное семейство линий (кромки стен, ряды сетки
габионов и т.п.) даёт точку схода на строке горизонта; наклон оси = `atan((cy − y_h) / f)`,
где `f ≈ 720 px` для 960×540 (дефолтный FOV игры 90° × зум прицела 1.5x; при другом FOV шкала
умножается на 720/f). Класс A — два независимых семейства согласны по строке горизонта
(случайная текстура так совпасть не может); поэтому измерения абсолютные и без накопления дрейфа.
Интегральный вариант (фазовая корреляция соседних кадров) даёт непрерывную кривую, но дрейфует
на склейках; покадровый — устойчивее и является основным.

Графики: `ciws/out/pitch_evolution_lines.png` (эволюция по линейным замерам),
`ciws/out/pitch_evolution.png` (интегральная), `ciws/out/pitch_perframe.png` (scatter A/B).
Данные: `ciws/out/pitch_perframe_2fps.csv` и др. Скрипты и инструкции по воспроизведению:
`ciws/scripts/`, `ciws/MANIFEST.txt`.

## Ограничения

- Публичных числовых значений угла наводки у игры нет (проверены гайды, вики, базы данных,
  community-дампы, патчноуты) — это измерительный результат, а не цитата.
- Абсолютная шкала зависит от f (FOV): ±10–20% → при «+1.9°» это ±0.3–0.5°.
- Погрешность методики (волнистость линий, дискретность): ±1…1.5°.
- Кадра с физическим упором ствола вниз в доступном материале нет; «≈0°» означает
  «ни разу достоверно не ниже горизонта», а не механически измеренный предел.
  Для ±1° нужен клип с упором вниз и двумя ортогональными семействами стен в кадре,
  либо файлы игры, либо замер в игре.
